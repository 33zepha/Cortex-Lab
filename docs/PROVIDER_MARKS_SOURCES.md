# Public provider marks

The public Cortex journey uses monochrome marks as visual references for the provider ecosystem. They are not a claim that every provider is enabled in every Cortex deployment.

- Claude: existing local `ClaudeMark` component, based on the Anthropic/Claude sunburst treatment already used in the product UI.
- Codex / OpenAI: existing local `OpenAiMark` component, based on the OpenAI knot mark already used in the product UI.
- DeepSeek, Google Gemini and Mistral AI: path data sourced from the corresponding entries in [Simple Icons](https://simpleicons.org/) 16.28.0. The Simple Icons project distributes its icon set under CC0; the project source and version are recorded here for traceability.

All marks are rendered as one muted monochrome treatment in the landing scene. Provider availability remains dependent on the connected runtime and deployment configuration.
